# User guide

1. Launch with `mvn javafx:run`.
2. Select a module from the dashboard sidebar.
3. Enter values in the form and use **Run** or **Start**.
4. Use step, pause, resume, and reset controls where available.
5. Review the visual result and performance metrics.
6. Open **Performance Analytics** to filter history and export CSV or PDF reports.

## Demonstration sequence

1. Run FCFS and Round Robin with the same process set.
2. Compare First Fit, Best Fit, and Worst Fit on fragmented memory.
3. Show a safe and unsafe Banker's matrix.
4. Run ordered dining philosophers and briefly demonstrate naive acquisition.
5. Open Analytics and export the recorded history.

Invalid values are reported in an error dialog. Stop a live synchronization simulation
before leaving its screen if you want its latest snapshot recorded.
